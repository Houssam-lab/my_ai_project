# بحث حسابي موجّه نحو أول صفقة (Account-Based Deal Research)
## من «نوع العميل» إلى: اسم محدد + دليل + قناة + رسالة + أقصر طريق لأول دفعة

**تاريخ الإصدار:** سبتمبر 2026 · **المنهج:** Account-Based Research + Buyer Intelligence + Pain Mining + Purchase-Signal Detection + Contact Discovery + Deal Path Mapping.
**قاعدة الصرامة:** لا اسم إلا بمصدر. كل ادعاء مربوط برابط. التصنيف: **[E] Evidence** مثبت · **[I] Inference** استنتاج · **[U] Unknown** مجهول. وكلمة «دفع مضمون» ممنوعة ما لم يكن هناك طلب شراء/عقد/مناقصة/التزام ميزانية.

## المرحلة 1 — ما الذي نبيعه بالضبط (اقتصاديات العرض قبل الأسماء)

**السلعة الأساسية في هذا التقرير:** خدمة **حجز اجتماعات مؤهلة (Outbound / Appointment Setting)** لشركات B2B، مباعة بالنتيجة لا بالساعة — مع خطّين مساندين متحققين سابقًا: **خلية عربية للوكالات** و**بيانات/تقييم AI عربي**.

| السؤال | الإجابة |
|---|---|
| المشكلة الاقتصادية | «لا إيراد بلا مواعيد»: نمو pipeline يتوقف عند غياب outbound منظَّم |
| لمن تحل؟ | شركة B2B صغيرة/mid-market (50–500 موظف) لديها منتج يبيع بالفعل ونمو مُعلن |
| النتيجة القابلة للقياس | **عدد الاجتماعات المؤهلة المُعقدة/المحفوظة شهريًا** (held meetings)، لا « Leads » |
| تكلفة عدم الحل | ✅ بديل داخلي **9,800–14,200$/شهر** لكل مقعد SDR بعد التهيئة [1](https://outboundsalespro.com/outsourced-sdr-pricing-2025/)؛ بديل وكالة **من 5,000$/شهر** (Belkins: 100 مواعيد/سنة) [2](https://www.revenueflow.com/blog/appointment-setting-companies)؛ تكلفة اجتماع داخلي **821–1,150$** [1](https://outboundsalespro.com/outsourced-sdr-pricing-2025/) |
| البديل الحالي | توظيف داخلي (بطيء 3–4 أشهر تهيئة) أو وكالة (عقود 3–6 أشهر) أو لا شيء (مؤسس يبيع بنفسه) |
| لماذا يدفع بدلًا من لا شيء؟ | لأن «لا شيء» = فاتورة ربع سنوي فارغة؛ والحلول الثلاثة كلها مدفوعة أصلًا [E] |
| B2B أم B2C؟ | B2B صافٍ |
| قرار فردي أم مؤسسي؟ | **فردي** في شركات <200 موظف (VP Sales/CEO يقرران وحدهما) |
| أقل نسخة تُباع لأول عميل | **تجربة 21–30 يومًا: 8 اجتماعات مؤهلة مقابل ~1,200–1,600$ (أو 200$/موعد)** عبر escrow/عقد صغير |
| ما يمكن شراؤه اليوم بلا مشروع ضخم | نفس التجربة أعلاه — بلا تغيير أنظمة، بلا توظيف، بلا عقد طويل |

**الخطّان المساندان (نفس منطق النتيجة):**
- **بيانات AI عربي:** النتيجة = مهام تقييم/وسوم مُسلَّمة بأجل محدد. دليل سعر: OpenTrain العربية QA **35–40$/ساعة** [3](https://www.opentrain.ai/jobs/arabic-quality-assurance-lead--cmrc2gyew0005lp3l28y1p78x/)، Prolific **30$/ساعة** [4](https://www.indeed.com/q-remote-jobs-arabic-jobs.html)، Sigma توظف مهام **عربية مغاربية وتشمل الجزائر صراحة** [5](https://careers.sigma.ai/jobs/5035995-maghrebi-arabic-linguistic-projects-remote).
- **خلية عربية:** النتيجة = تسليم مشاريع EN→AR بموعد. دليل: مشاريع عربية تُنشر يوميًا على ProZ وميزانيات Upwork ظاهرة (تقرير 33 ألف كلمة بـ800$) [6](https://www.upwork.com/freelance-jobs/translation-english-arabic/) — مرجع سابق من فحصنا.

### مسار الصفقة — LearnWell
أنا ← LinkedIn/وظيفة مفتوحة ← مسؤول الـBD (أو CEO مباشرة) ← صاحب المشكلة (فريق النمو) ← القرار (CEO/VP) ← الاعتراض (توظيف داخلي/ثقة) ← عرض التجربة ← Proof (3 رسائل عينية + تقرير أسبوعي) ← تجربة مدفوعة 8 مواعيد ← retainer. **نقاط الانهيار المحتملة:** عدم الرد (نعالجه بمسار مزدوج: رسالة + تقدم على الوظيفة كـ«contract BDR») · الاعتراض الجغرافي (نعالجه بـescrow) · عدم تأهيل المعيار (نعالجه بـICP مكتوب قبل الدفع).
